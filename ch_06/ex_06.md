# Solution

1. Parameters are initialized with arguments and destroyed after function. Local variables are also destroyed after function, but they're initialized if their definition contains an initializer. On the other hand, the local static variables are initialized in first call of that method and doesn't destroyed after function end.

2. Parameters are useful when one need to pass a value to function.
3. Local variables are always needed when one need to store a value for expressions.
4. Local static variables might be need for counting specific intentions in functions.
