# Solution

I prefer `using`. It doesn't hide like `auto` or doesn't need another example like `decltype`.

a.

```c++
using strT = std::string[10];
strT &func(void);
```

b.

```c++
auto func() -> std::string(&)[10];
```

c.

```c++
std::string anotherArr[10];
decltype(anotherArr) &func();
```
