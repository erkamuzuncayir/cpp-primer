# Solution

1. `const int v2 = 0; int v1 = v2;`
    - `v2` has a top level const.

2. `int *p1 = &v1, &r1 = v1;`
    - neither has a const.

3. `const int *p2 = &v2, *const p3 = &i, &r2 = v2;`
    - `p2` has a low level const, `p3` has both level const, `r2` has a low level const.
