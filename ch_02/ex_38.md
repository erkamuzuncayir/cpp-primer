# Solution

- `decltype` uses top-level const and references, while `auto` not.

    ```c++
    const int a = 3;
    decltype(a) b = 2;  // Ok. b is an const int.
    auto c = a;         // Ok. c is an int.
    
    int d = 2;
    int &e = d;
    decltype(e) f = d;  // Ok. f is reference to d.
    auto g = d.         // Ok. g is 2.
    ```

- we can use functions to get desired type with `decltype`, but with `auto` we can't. 
    
    ```c++
    decltype(f()) b = 2;  // Ok. It uses return type of f function
    auto f() c = a;       // Error.
    
    ```
