# Solution

- `list` will be useful when there are lots of insertion/deletion operations needed.
- `vector` will be useful when there are numerous random-access needed.
- `deque` will be useful when queue-like structure needed.
- `map` will be useful when access through key needed instead of index.
- `set` will be useful when fast value check needed.
