# Solution

1. `string null_isbn("9-999-99999-9");`: `null_isbn` string created with `"9-999-99999-9"`.
2. `Sales_data item1(null_isbn);`: `item1` Sales_data created with `null_isbn`.
3. `Sales_data item2("9-999-99999-9");`: It creates a string object from `"9-999-99999-9"` then initialize `item2` with this object.

After making `explicit`. Third one gives error. Because it needs implicit conversion that `explicit` keyword doesn't let.
