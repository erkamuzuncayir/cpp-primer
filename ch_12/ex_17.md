# Solution

- IntP p0(ix);
  - illegal for a compiler error. `ix` is not a pointer.
- IntP p1(pi);
  - illegal for a runtime error. the memory `pi` points to is not a dynamically allocated, thus it can't be freed.
- IntP p2(pi2);
  - legal but not recommended. `pi2` shouldn't use `delete`.
- IntP p3(&ix);
  - illegal for a runtime error. `ix` is not a dynamically allocated, thus it can't be freed.
- IntP p4(new int(2048));
  - legal.
- IntP p5(p2.get());
  - illegal due to runtime error. both `unique_ptr` points the same object and this will cause a double delete situation.
