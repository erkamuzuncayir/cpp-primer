# Solution

- `process(sp);`
  - legal. creates copy of `sp` and pass into `process`.
- `process(new int());`
  - illegal. `process` expects a `shared_ptr<int>`, so this is a type mismatch. 
- `process(p);`
  - illegal. `process` expects a `shared_ptr<int>`, so this is a type mismatch.
- `process(shared_ptr<int>(p));`
  - legal but dangerous. creates a new `shared_ptr<int>` from the `p` and pass into `process`. Now two pointer points same `int` and they don't know about other pointer. It may create double delete situation.
