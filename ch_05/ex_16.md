# Solution

I'd probably choose while loop, because there are places we don't know how many times we need iterate.

```c++
// while input
char input;
while (cin >> input)
    // ...

// for input
for (int input = 0; cin >> input;)
    // ...

// for iteration
for (int i = 0; i != size; ++i)
    // ...

// while iteration
int i = 0;
while (i != size)
{
    // ...
    ++i;
}
```
