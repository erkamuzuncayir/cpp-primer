# Solution

- It assigns one instance of object to other one when assign operator used.
- It assigns each nonstatic member of rhs to lhs object and returns a reference to it's lhs object.
- If class doesn't explicitly define a copy-assignment operator, compiler will be automatically synthesizes one.
