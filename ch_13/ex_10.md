# Solution

`StrBlob`'s `shared_ptr` decreases reference count, if no other `shared_ptr` instances are pointing to the same vector, the vector is destroyed, and its memory is freed. However, `StrBlobPtr` uses a `weak_ptr` so, it doesn't control the lifetime of the underlying object. Therefore, it didn't do anything to underlying object, it simply disappears.
