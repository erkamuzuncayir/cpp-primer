# Solution

1. Input iterators: ==, !=, ++, *, ->
2. Output iterators: ++, *
3. Forward iterators: ==, !=, ++, *, ->
4. Bidirectional iterators: ==, !=, ++, --, *, ->
5. Random-access iterators: ==, !=, <, <=, >, >=, ++, --, +, +=, -, -=, -(two iterators), *, ->, iter[n] == * (iter + n)
